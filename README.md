# Engineering Knowledge Assistant
A multi-tenant internal knowledge assistant that lets engineering teams
upload documents, ask questions, and receive cited answers.

## Problem
Engineering teams lose time searching across PDFs, wikis, runbooks,
meeting notes, and Slack threads.

## Solution
Upload documents, automatically index them, ask questions, and receive
answers with source citations.

## Core Workflow
Upload → Ingest → Chunk → Embed → Search → Answer with Citations

## Tech Stack
- Java 17
- Spring Boot 3
- PostgreSQL + pgvector
- React + TypeScript
- Docker Compose
- Testcontainers
- GitHub Actions

## Features
- JWT authentication
- Multi-tenant workspaces
- Role-based access control
- Async document ingestion
- PDF and Markdown support
- Semantic search
- Hybrid retrieval
- Cited answers
- Feedback collection
- Audit logging
